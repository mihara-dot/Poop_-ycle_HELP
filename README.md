# Лабораторная работа №2

## Описание

Программа рассчитывает тепловой поток через стенку трубопровода для различных значений наружного диаметра трубы.

В программе используются два цикла:
- `do while` — для первого участка значений диаметра;
- `while` — для второго участка значений диаметра.

## Ввод данных

Программа запрашивает с клавиатуры следующие данные:

- `liquidTemperature` — температура жидкости;
- `ambientTemperature` — температура окружающей среды;
- `innerDiameter` — внутренний диаметр трубы в сантиметрах;
- `coefficientThermalConductivity` — коэффициент теплопроводности;
- `coefficientHeatDissipation` — коэффициент теплоотдачи;
- `pipeLength` — длина трубопровода в метрах.

Значения наружного диаметра `d0` программа формирует автоматически с помощью циклов.

Первый участок:
- от 9,1 до 9,5 см;
- шаг 0,1 см.

Второй участок:
- от 11 до 15,5 см;
- шаг 1,5 см.

## Запуск

1. Открыть файл `.cpp` в среде разработки.
2. Скомпилировать программу.
3. Запустить программу.
4. Ввести запрашиваемые значения с клавиатуры.
5. Получить рассчитанные значения теплового потока `Q` для каждого значения наружного диаметра.

## Результат

Программа выводит на экран значение наружного диаметра `d0` и соответствующее ему значение теплового потока `Q`.
